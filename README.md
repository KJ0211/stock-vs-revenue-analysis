# Stock vs Revenue Analysis

## Overview
This project explores the relationship between company stock prices and quarterly revenue to assess whether market performance reflects business fundamentals.

## Business Question
Do stock prices accurately reflect a company’s revenue performance over time?

## Data Sources
- Yahoo Finance (stock price data via yfinance)
- Publicly available revenue tables scraped from financial websites

## Tools & Technologies
- Python (Pandas, Matplotlib)
- BeautifulSoup
- Regex

## Project Structure
This repository is organized into data collection, data processing, analysis, and visualization components to ensure clarity and reproducibility.
